# Screen-Stocks-stats-menu
A in game menu for the indie game "Screen Stocks" with quality of life features and other cool stuff

# Current Features:
default stats all in one menu\
how much you've made in that session\
live stock charts with real time pricing and your gain or loss and what you bought it for\
customizablety, follow the games theme or make you own in the settings\
put it anywhere you want on the game screen\
